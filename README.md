# Калькулятор військової пенсії

**Адвокат Дмитро Лапоша** | Київ, Україна

🔗 Онлайн-версія: https://dlaposha.github.io/pension-calculator-dovidka/

## Можливості

- ✅ Розрахунок пенсії за вислугою, інвалідністю, змішаним стажем
- ✅ Урахування індексацій 2022–2026 (постанови КМУ №118, №168, №185, №209, №210)
- ✅ Доплата 2000 грн (постанова №713) — автоматичне визначення права
- ✅ Прогресивні коефіцієнти обмеження (2025–2026)
- ✅ Порівняння довідок: попередження, якщо нова довідка невигідна
- ✅ Експорт у PDF, копіювання таблиці, поділ посиланням
- ✅ Збереження даних у браузері (localStorage)

## Використання

1. Відкрийте [онлайн-калькулятор] https://dlaposha.github.io/pension-calculator-dovidka/
2. Введіть дані довідки про грошове забезпечення
3. Оберіть статус, надбавки, параметри індексації
4. Натисніть "РОЗРАХУВАТИ"
